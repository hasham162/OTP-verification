# OTP Verification

React Native / Expo application for Quiz 4.

## Current status

The basic phone-number OTP UI is implemented.

Firebase/Twilio SMS verification will be connected later.

## Run

```bash
npm install
npx expo start
```

## Quiz requirements

- Enter phone number
- Request OTP
- Enter OTP
- Verify OTP
- Display success/failure message

The SMS/verification backend is the next step.
